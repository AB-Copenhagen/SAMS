- Committed (`5e9ec21`) and PR opened: https://github.com/AB-Copenhagen/SAMS/pull/126, merged. `/api/system/migrate-embed-token` called against production.
- [repo-wide] Live-verification bug found immediately on the very first real embed test: `resolveEmbedTarget`/`resolveEmbedAssetTarget`'s asset branch also required `asset.isPublic` (copied from the sibling `getAssetByShareToken`'s gate during Phase 1/2), so any embed 404ed unless its target *also* had the unrelated share-link "Public link enabled" toggle on — a dependency never surfaced anywhere in the embed-issuance UI. Confirmed via `curl -D-` on the live embed URL: `x-matched-path: /embed/[token]` (route matched fine) but body "This page could not be found" (resolution returned null). Root cause traced from the code alone, no DB access needed to diagnose. Fixed by dropping the `isPublic`/password re-check from resolution entirely (renamed `getEmbeddableCollection` → `loadCollectionWithRules`, now a plain lookup) — an `EmbedToken`'s own existence/revocation is the authorization, matching the "distinct, independent, permanent until revoked" design the spec called for throughout. Promoted to `.dmx/techContext.md`/`.dmx/systemPatterns.md`.
